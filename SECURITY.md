# Security Policy

## Supported versions

Inbox Sentry is a free Grok Bot template. Security fixes apply to the current published template and the docs in this repository.

## Reporting a vulnerability or bypass

If you believe you have found a way to bypass Inbox Sentry — for example, a prompt-injection technique that is rated too weakly, or behavior that causes the bot to act on injected instructions — please report it **privately**.

Use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) on this repository:

1. Open the **Security** tab on this repo.
2. Choose **Report a vulnerability**.
3. Describe the bypass at a high level: what category of attack it is, what verdict you expected, and what verdict (or action) you observed.

**Do not** paste real email bodies, headers, personal names, addresses, or authentication codes into the report. Summarize the technique; use fictional example domains (such as `example.invalid`) if you need to illustrate structure.

We will acknowledge reports and work on a fix or docs update as appropriate. Public Issues are the right place for false alarms, missed attacks that are already public knowledge, and feature requests — not for unpatched bypass details.
